01Architecture Overview

cabin_sim/cognition.py is the Python authoritative mind: BDI deliberation, associative memory, mood & trust dynamics, the ride script and the experimenter chat all live in the Mind class — on the server. world/cabin  -->  Mind.step(dt)  -->  schema snapshot  -->  view (JS)

The boundary rules

  • Only SimEngine advances the clock. The server's ticker thread calls engine.tick(1) every interval wall-seconds; the browser never simulates time. engine.t and mind.t advance together by tick_dt each decision step.
  • Only schema.build_snapshot produces state. Everything the view knows arrives in one JSON document; it never reads world/agent/session internals (§07).
  • The view never decides. It may compute display-only figures, but nothing feeds back: seat input travels POST /api/seat → clamped by world.Seat → mind.note_user_input() (sets belief.user_hands for 3 s).
  • The model reasons; the body stays Python. In llm mode every decide beat is examine → reconsider → act (§10): the model picks the axis, the delta — or to sit still — and Python only whitelists the vocabulary and clamps the travel; the real outcome (as asked / clamped / refused) is fed back into the next beat. In rules mode no model runs at all and behaviour is byte-identical to the port (§09).
  • Determinism is guaranteed for --provider scripted only — all randomness is seeded and snapshot building consumes none (§09).

Two piecewise-linear tables score "how good is this seat pose", looked up by rate() — the same clamped interpolation the JS original had:

       (150, 0.4286), (180, 0.6071), (210, 0.4286), (240, 0.5333),

def rate(tbl, x):          # clamped piecewise-linear lookup (the JS rate())
    if x <= tbl[0][0]:  return tbl[0][1]     # below range → first value
    if x >= tbl[-1][0]: return tbl[-1][1]    # above range → last value
    ...                                   # lerp between the bracketing pair
  • ROT — comfort per swivel heading in degrees: facing the road (0°/360°) scores 1.0, the pokey angles (60°/120°) score lowest; mid-weights at 180° (turned to the cabin) and 330°.
  • HGT — comfort per cushion height in cm across the 38–46 cm travel (44 cm — Phill's target — sits at 0.0455 on this curve).
  • Both are consumed only by comfort_target() (§05): 0.35·rate(ROT, rot) + 0.35·rate(HGT, hgt) + 0.30·fit.

03Main Loop

There is exactly one loop that matters, and it runs server-side, once per decision step: session.step_once() → Mind.step(tick_dt). The whole cognitive tick is this method:

def step(self, dt):
    """Advance the mind by dt sim-seconds. Called once per decision step."""
    if dt <= 0:
        return
    self.t += dt
    self._fire_events()                              # ride script, each event once

    # speed coasts toward the event's target          (k = dt·0.05)
    k = min(1.0, dt * 0.05)
    self.ride["speed"] += (self.target_speed - self.ride["speed"]) * k

    # mood relaxation
    ct = self.comfort_target()
    self.mood["comfort"] += (ct - self.mood["comfort"]) * min(1.0, dt * 0.06)
    self.ride["g"] *= math.exp(-dt * 0.3)
    self.ride["jolt"] *= math.exp(-dt * 0.35)
    if 540 < self.t < 570:
        self.ride["rain"] = min(1.0, self.ride["rain"] + dt * 0.08)   # rain window
    else:
        self.ride["rain"] *= math.exp(-dt * 0.18)
    self.mood["energy"] = max(0.05, self.mood["energy"] - dt * self.energy_drain)

    bs = self.suspicion_base                         # set-point, not a ratchet
    if self.mood["suspicion"] > bs:
        self.mood["suspicion"] = max(bs, self.mood["suspicion"] - dt * 0.004)
    else:
        self.mood["suspicion"] = min(bs, self.mood["suspicion"] + dt * 0.003)

    # cognition
    self.decay_memory(dt)                            # traces below 0.09 forgotten
    self.bdi_reason(dt)                              # perceive → desires → argmax → act
    self.sample()                                    # every ≥3 s: mood + trust charts

Beliefs — re-perceived every tick

def perceive_fit(self):
    f = self.seat_fit()
    self.belief["fit_rot"] = 1 - f["rot"]            # how wrong the swivel is
    self.belief["fit_hgt"] = 1 - f["hgt"]            # how wrong the height is
    self.belief["fit_gap"] = 1 - f["overall"]        # combined gap (dr+dh)/2
    self.belief["user_hands"] = (self.t - self._last_user_input) < 3   # 3 s window

The deliberation step

def bdi_reason(self, dt):
    self.perceive_fit()                              # beliefs from the real seat

    # a persistent fit gap erodes trust: the cabin ignores his body
    gap = self.belief["fit_gap"]
    gb = (gap - 0.3) * 2.4 if gap > 0.3 else 0.0
    if gb > 0:
        hands = 1.6 if self.belief["user_hands"] else 1.0
        self.mood["suspicion"] = min(1.0, self.mood["suspicion"] + dt * 0.006 * gb * hands)

    best, best_v = None, 0.0
    offered = []                                     # (goal, desire), legal only
    for goal in GOAL_CD:                             # settle · attend · calibrate
        if self.t - self.bdi["last"].get(goal, -99.0) < GOAL_CD[goal]:
            continue                                 # cooldown
        if not self._pre(goal):
            continue                                 # precondition
        v = self._desire(goal)
        if v > 0:
            offered.append((goal, v))
            if v > best_v:
                best, best_v = goal, v                # argmax = rule pick

    # LLM deliberation: choose among `offered` ONLY (§10) — legality (cooldowns,
    # preconditions) was decided above in Python; a bad answer keeps the argmax.
    self._pending_thought = None
    if self.reasoner and offered:
        choice, thought = self.reasoner.deliberate(
            self, [g for g, _ in offered], best)
        if choice in {g for g, _ in offered}:
            best = choice
        self._pending_thought = thought

    if best:
        self.bdi["intention"] = best
        self.bdi["since"] = self.t
        self.bdi["last"][best] = self.t
    else:
        self.bdi["intention"] = None

    if best == "settle":
        if self.self_adjust():                       # whitelisted seat actions
            ... alternating speak/think of THOUGHTS["settle"]
        else:
            self.think(self.pick_line(THOUGHTS["settleLow"]))   # couldn't move
    elif best == "attend":
        self.maybe_speak(self.think())               # recall a trace, maybe say it
    elif best == "calibrate":
        tw = self.trust_value()
        ... # ≥0.6 trustOk think · ≤0.38 trustLow think+maybe_speak · else intend

  • settle actuates through the same whitelist a human input uses (actions.apply(cabin, "seat_up" / "seat_down" / "rotate_cw" / "rotate_ccw") — fixed ±10 mm / ±10° steps, clamped by Seat; the mind gets no privileged path).   • attend retrieves the strongest memory trace, rehearses it (+0.22) and speaks the line with probability maybe_speak().
  • calibrate reviews trust only during the ride: ≥0.6 → trustOk thought; ≤0.38 → trustLow thought and possible speech; between the bands it just lights the intend module.
Why intention is sometimes null: that is faithful behaviour, not a bug — if every goal is inside its cooldown or fails its precondition for this tick, the agent idles with intention = null. With tick_dt = 2 you see it clearly: attend (cd 3.2 s) fires every other step.
Human override: any POST /api/seat stamps mind._last_user_input = mind.t; for the next 3 seconds belief.user_hands suppresses settle's precondition and multiplies its desire by 0.15 (and ×1.6 on the erosion term) — the machine waits while you drag the dial. Speech is probabilistic: freq = talkativeness · (0.4 + 0.3 if susp > 0.62 + 0.25 if comfort < 0.35) — a wary, uncomfortable Phill talks more.
04Memory System

Associative traces with exponential decay (ACT*-flavoured, exactly as the JS had it). Ride events, seat adjustments and the experimenter's questions all enter through the same door:

class Memory:
    """Associative traces with exponential decay (ACT*-flavoured, as in JS)."""

    def remember(self, trace_id, label, salience, important, t):
        act = min(1.0, salience + (0.1 if important else 0.0))
        self.traces.append({"id": trace_id, "label": label, "salience": salience,
                            "act": act, "born": t, "rehearsed": 0})
        if len(self.traces) > self.cap:            # cap 8 — FIFO evict
            del self.traces[: len(self.traces) - self.cap]

    def decay(self, dt, t):                        # called once per tick
        dead = []
        for tr in self.traces:
            tr["act"] *= math.exp(-self.lam * dt)  # λ = 0.004 /s
            if tr["act"] < self.floor:             # floor 0.09
                dead.append(tr)
        for tr in dead:                            # → forgot ring (6) + count
            self.traces.remove(tr)
            self.forgot.append({"label": tr["label"], "age": ...})
            self.forgot_count += 1

    def pick(self):                                # retrieval = highest activation
        return max(self.traces, key=lambda tr: tr["act"])

    def rehearse(self, tr):                        # recalling strengthens
        tr["rehearsed"] += 1
        tr["act"] = min(1.0, tr["act"] + self.rehearsal)   # +0.22, cap 1.0

Worked example

remember("bump", salience 0.795) → act = 0.795 after 480 s: act = 0.795 · e^(−0.004·480) = 0.1166 still remembered (> 0.09) after 960 s: act = 0.1166 · e^(−1.92) = 0.0171 < 0.09 → forgotten forgot ring: [{label, age}], count++
  • Encoding: salience = max(0.35, 0.42 + impact·0.5) where impact = max(g, jolt); important kinds (bump · arrive · workzone) get +0.1; chat lines enter as remember("chat", "Experimenter: …", 0.5, important=True) (§08).
  • Retrieval: pick() returns the strongest trace; think() then quotes THOUGHTS[trace.id] and rehearses it (+0.22) — recall feeds itself.
  • Capacity: 8 traces, oldest evicted silently (FIFO); traces that decay past the floor are remembered as forgotten in a ring of 6 plus a counter — the HUD shows both.
  • Publishing: memory.view(t) → snapshot agent.memory: [{id, label, act, age, rehearsed}]; forgot_view() / forgot_count → agent.forgot / agent.forgotCount (§07).

At λ = 0.004/s a trace's activation halves every ~173 s (ln2/λ) — a mid-salience event stays quotable for roughly 6–10 minutes of ride: long enough that attend keeps re-reading the pothole at 258 s while still motorway-bound, short enough that the summary screen shows real forgetting by 600 s.
05Trust & Mood Dynamics

Seat fit (canonical units)

rot = seat.rotation_deg mod 360 hgt = seat.height_mm / 10 (mm → cm) dr = min(1, |rot − target_rot| / 180) dh = min(1, |hgt − target_hgt| / 8) fit = { rot: 1−dr, hgt: 1−dh, overall: 1 − (dr+dh)/2 } fitGap = 1 − overall Phill starts as-found (90° / 38 cm) → gap 0.625

Comfort — attractor blend

comfortTarget = clamp01( 0.35·rate(ROT, rot) + 0.35·rate(HGT, hgt) + 0.30·fit.overall ) comfort += (comfortTarget − comfort) · min(1, dt·0.06)

With the seat settled forward at 44 cm: 0.35·1.0 + 0.35·0.0455 + 0.30·1.0 = 0.6659 — the live snapshot converges to exactly that. The rate tables (ROT, HGT) are the thesis reference data, unchanged (§02).

Live trust

trust.live = clamp01( 0.34·comfort + 0.40·(1 − suspicion) + 0.16·ev + 0.10·(1 − fitGap) ) where ev = clamp01(1 − jolt / 0.6) worked example: comfort 0.5, susp 0.3, jolt 0.3, fitGap 0.2 = 0.34·0.5 + 0.40·0.7 + 0.16·0.5 + 0.10·0.8 = 0.61

Suspicion — set-point, not a ratchet

  • Base set-point 0.5 (persona mood.suspicion); drifts back at −0.004/s above it, +0.003/s below (every tick, in step).
  • Priors re-baseline it for the next ride: base = clamp01(0.5 + (0.5 − prior_trust)·0.35) — a wary last ride starts this one slightly more suspicious (persisted as aggregate JSON, no personal data).
  • The cabin ignoring his body is itself suspicious: the fit-gap erosion term in §03 pushes +dt·0.006·gb every tick the seat stays wrong, ×1.6 while the human is dragging.

def perceive_event(self, ev):
    impact = max(ev["g"], ev["jolt"])
    salience = max(0.35, 0.42 + impact * 0.5)         # encoding strength (§04)
    important = ev["kind"] in IMPORTANT_KINDS
    self.remember(ev["kind"], ev["label"], salience, important)

    self.target_speed = float(ev["spd"])              # speed coasts toward it
    self.ride["g"] = ev["g"]
    self.ride["jolt"] = ev["jolt"]                    # decays on later ticks

    if ev["jolt"] > 0.3:
        self.mood["suspicion"] = min(1.0, self.mood["suspicion"] + 0.20)
        self.mood["comfort"] = max(0.0, self.mood["comfort"] - ev["jolt"] * 0.12)

    if ev["kind"] == "rain":                          # +0.04 susp

def chat_send(self, raw):
    text = str(raw or "").strip()
    if not text:
        return {"ok": False, "error": "empty message"}
    self.chat.append({"who": "experimenter", "t": self.t, "text": text})
    self.log_line("chat", f"experimenter · {text}")
    self.remember("chat", f"Experimenter: {text}", 0.5, True)   # encoded into memory (§04)
    reply, res, outcome = None, None, None
    if self.reasoner is not None:
        # llm lane: the MODEL interprets the message — question, small talk, or
        # an order. An immediate move runs through _perform() (the same
        # whitelist/clamp bridge as the decide cycle); a longer order stands as
        # `instruction` until a decide beat reports "order_done": true. No
        # regex directive table runs on this path.
        res = self.reasoner.chat_act(self, text)
        if res:
            reply = res["reply"]
            if isinstance(res.get("action"), dict):
                ok, detail, _ = self._perform(res["action"], source="chat")
                outcome = detail if ok else f"REFUSED — {detail}"   # "height_mm 380 → 410"
            if res.get("standing"):
                self.instruction = text                     # the order STANDS (§10)
                self.remember("order", f"Standing order: {text}", 0.6, True)
                if outcome is None:
                    outcome = "order accepted — first move on the next think beat"
    if reply is None:
        # rules mode — and the degrade path when the model is unreachable:
        # orders by regex, then phrase-bank conversation
        reply = self._directive(text) or self._chat_reply(text)
        if self.reasoner is not None:
            # that fallback line may SOUND compliant while nothing moves —
            # say so, so a rate-limited no-op can never pass for success
            outcome = ("the model did not answer this time (rate limit or "
                       "network) — the line above is a fallback, no seat "
                       "move was made")
    self.chat.append({"who": "phill", "t": self.t, "text": reply})
    if outcome:
        self.chat.append({"who": "cabin", "t": self.t, "text": outcome})
    del self.chat[: max(0, len(self.chat) - 40)]                # history capped at 40
    self.speak(reply)                                           # → speech in next snapshot
    result = {"ok": True, "reply": reply, "state": self.chat_state()}
    if self.reasoner is not None:      # llm lane: always report honestly;
        result["outcome"] = outcome    # the rules payload keeps its old shape
    return result

09Determinism

The port's hard guarantee: two engines built with the same seed produce byte-identical snapshots — for the scripted provider. Everything rests on two facts:

# cabin_sim/cognition.py — Mind.__init__
self.rng = random.Random(seed)     # the ONLY randomness the mind ever draws

# cabin_sim/sim.py — SimEngine.__init__
self.rng = random.Random(seed)     # the engine's own seeded rng
self.t   = 0.0                     # sim clock: tick counts, never wall time
  • Every draw goes through mind.rng: phrase choice (pick_line → int(rng.random()·n) % n), the speech chance in maybe_speak(), the event speech flip rng < 0.5. Nothing else is stochastic — mood relax, memory decay, cooldowns and clamps are pure arithmetic.
  • Snapshot building consumes no randomness: build_snapshot is documented pure — reads engine/session only, does not mutate; two calls with the same engine state return identical dicts.
  • The clock is tick-driven: the ticker's wall-clock sleeps only pace steps; engine.t advances by tick_dt per step, so timing never leaks in from the host machine.
  • Seeds flow from one flag: --seed (default 1) → Session(seed=…) → Mind.rng, and SimEngine(seed=…) → its rng. POST /api/control {"reset": true} rebuilds session + engine from the same persona/provider/seed — the restarted run replays identically.

Where the guarantee stops

  • --provider scripted only. All randomness is seeded and snapshot building consumes none; LLM providers are not deterministic — that is the trade of §10, contained by validation and rule-fallbacks (the ride itself still follows the same script, mood and cooldowns).
  • Pytest forces rules mode (scripted provider → create_reasoner returns None), so the suite is deterministic by construction.

cabin_sim/reasoning.py — the model IS the reasoner; Python is the body it lives in. The split is stated in the module docstring:

def create_reasoner(provider, mode="auto", persona=None, chat_provider=None,
                    environment=None):
    """Build the reasoner for this session (None = rules mode).
    Never raises: an unusable 'llm' request degrades to rules with a warning,
    so a missing key or stopped Ollama can never take the ride down."""
    mode = (mode or "auto").lower()
    backend = getattr(provider, "name", "scripted")
    if mode == "auto":
        mode = "llm" if backend != "scripted" else "rules"
    if mode == "llm":
        if backend == "scripted":
            print("reasoning: 'llm' needs a real provider (groq/ollama) — "
                  "using rule-based reasoning.", file=sys.stderr)
        else:
            return LLMReasoner(provider, persona,
                               chat_provider=chat_provider,
                               environment=environment)
    return None

  • Providers: scripted (deterministic stand-in, no key), ollama (fully local via OLLAMA_BASE_URL, default model llama3.2 — any model via OLLAMA_MODEL), groq (free cloud tier, code default allam-2-7b via GROQ_MODEL, temperature 0.7, max 240 tokens; the running setup overrides it in .env — GROQ_MODEL=openai/gpt-oss-20b ticks, CHAT_MODEL=gpt-oss-120b chats). create_provider() honours --provider then .env, and unknown config falls back to scripted with a warning.
  • Hybrid chat backend: --chat-model / env CHAT_MODEL selects a SECOND model used only for experimenter replies — the fast model ticks, the bigger model chats (§08); unset = the same model does everything.
  • Live switching: set_environment() / set_persona() rebuild the system prompt on the running reasoner — the buttons of the live prompt layer (§11).

    'recline_deg|rotation_deg", "delta": <number>} or '
    '{"kind": "vending", "item": "snack|water|coffee"} or '
    '{"kind": "table", "folded": true|false} or null, '
    '"say": "<one short line you say out loud, or empty>", '
    '"order_done": <true only if a standing order is fulfilled>}'
)
  • state_block() is one compact STATE line built from the authoritative mind only — the same facts the snapshot publishes, so the model can never contradict observable state (seat, prefs, fit gap, user hands, mood, live trust, ride, top-3 memories with activations, last said).
  • outcome_block() is the feedback half: done: height_mm 380 → 410 | seat now 45° / 410mm / slide 350mm — or REFUSED: … — so the next call examines the real world, not the model's intention; before the first action it reads "nothing yet — you have just sat down".
  • The system prompt anchors the persona (the self intro, traits, the voice — "dry, practical, British understatement; short first-person lines") plus the ENVIRONMENT world text from prompts/ (§11), with the RULES: never invent numbers, never break character, answer with the requested JSON only.
  • Validation & containment: extract_json tolerates fences/prose; clean_line strips and truncates to MAX_THOUGHT = 160 / MAX_REPLY = 240 chars; the action is checked for SHAPE only — the physical referee is actions.apply_llm_action() (whitelist + world clamps), whose real result comes back as mind.last_outcome. Rates: THROTTLE_S = 12.0 sim-seconds between decide calls (sized to the Groq free tier — zero 429 churn), SPEAK_GAP_S = 30.0 wall-seconds shared by every lane (decide, speak and chat all stamp it, so they can never crowd the free tier at once), one retry after RETRY_BACKOFF = 4.0 wall-seconds (measured: 1.5 s lands inside the same 429 window, 4 s crosses its edge). Chat itself is not throttled — the experimenter is waiting for the answer.
  • What the model never touches: mood relaxation, memory decay / rehearsal / salience, the ride script, the seat's travel clamps and the action vocabulary — and a throttled or failed beat is a quiet beat: no rule fallback, no invented behaviour, the person simply sits still until the next allowed call.
Inner monologue: examine and reconsider land in the thoughts ring through think() (newest on top: what the outcome meant, then what he wants now), say becomes speech in the next snapshot, and the whole beat is recorded as mind.cycle / popped by consume_cycle() into the session log — while the memory side effects of think() (rehearse, rotation-flush) have already happened Python-side and stay authoritative.
Ride never breaks: missing key, stopped Ollama, rate limit, garbled JSON — a failed decide is a quiet beat (the mind sits still until the next allowed call; no rule fallback, no invented behaviour); a failed chat still answers from the rules lane but adds the honest outcome line "no seat move was made" (§08); a failed cycle never crashes a tick. The mode is observable at any time via snapshot.agent.reasoning.
