01BDI Architecture Overview

cabin_sim/cognition.py runs the mind of Phill, the synthetic passenger of the self-driving cabin. It is a classic Belief–Desire–Intention agent (Bratman) — but after the port it is no longer embedded in the browser. The Python package is authoritative: it owns state, decides, and publishes a versioned snapshot. The three.js/canvas page became a view adapter (src/cognitive.js) that polls, draws and forwards input; the pre-port mind is archived unchanged in src/cognitive.legacy.js.

┌──────────────────────────────────────────────┐ │ VIEW src/cognitive.js (thin adapter) │ │ canvas + HUD render V · input dials · rAF loop │ └───────▲───────────────────────┬──────────────────┘ │ GET /api/snapshot │ POST /api/seat · /api/chat · /api/control ┌───────┴───────────────────────▼──────────────────┐ │ TRANSPORT cabin_sim/server.py (stdlib HTTP) │ │ ticker thread → engine.tick(1) every interval │ └───────▲───────────────────────────────────────────┘ │ build_snapshot(engine) ┌───────┴───────────────────────────────────────────┐ │ CLOCK + CONTRACT sim.py · schema.py │ │ engine.t · phase machine · seeded rng · priors │ └───────▲───────────────────────────────────────────┘ │ session.step_once() → mind.step(dt) ┌─────────────────────┴───────────────────────────────────────────────┐ │ CORE (authoritative) │ │ cognition.Mind ← world.Seat · actions gate · agent · provider │ │ perceive → desire → intention → act, once per decision step │ └──────────────────────────────────────────────────────────────────────┘

The three-layer rule

  • Only SimEngine advances the clock. The server's ticker thread calls engine.tick(1); the browser never simulates time. engine.t and mind.t advance together by tick_dt each decision step.
  • Only schema.build_snapshot produces state. Everything the view knows arrives in one JSON document; it never reads module internals.
  • The view never decides. It may compute display-only figures (rate-table gauges, fit text, timeline markers), but nothing feeds back: seat input goes through POST /api/seat, which is clamped by world.Seat and sets the mind's belief.user_hands.

Who reasons (new): cabin_sim/reasoning.py plugs an LLM into three points — the intention choice (only among Python-legal goals), the inner-monologue thought, and chat replies. --reasoning auto|rules|llm: auto enables the model whenever the provider is real — by default the Groq free tier (allam-2-7b, ~300 ms/call, key in .env) — or a local Qwen 3 via Ollama (--provider ollama, offline fallback) — while rules keeps the deterministic phrase banks (pytest). Any illegal choice, bad JSON, rate limit or network error falls back to rules for that tick: the ride never breaks.
Determinism: with --provider scripted, the only randomness is Mind.rng (a random.Random(seed) created with the session seed) plus the engine's own seeded rng. Two engines with the same seed produce byte-identical snapshots — guarded by tests/test_determinism.py and test_cognition.py.

03Main Cognition Loop

There is exactly one loop that matters, and it runs server-side, once per decision step:

ticker thread every interval wall-s → engine.tick(1) └─> session.step_once() ├─ agent.decide() provider: scripted | groq | ollama ├─ actions.apply(...) whitelist + Seat clamps ├─ agent.observe(...) drink/adjust impulses on the shared mood dict └─ mind.step(tick_dt) the ported cognitive core ├─ self.t += dt ├─ _fire_events() ride script, each event once ├─ speed coasts to the event's target (k = dt·0.05) ├─ mood: comfort → comfortTarget, g/jolt decay, rain window, │ energy −0.00018·dt, suspicion → set-point ├─ decay_memory(dt) traces below 0.09 are forgotten ├─ bdi_reason(dt) perceive → desires → argmax → act └─ sample() every ≥3 s: mood + trust for charts engine.t += tick_dt (same dt — the two clocks advance together) view loop (browser, passive) GET /api/snapshot every pollMs (700 ms) └─ applySnapshot(s) → V → renderAll() + publishCog() rAF draws V at 60 fps

The deliberation step

def bdi_reason(self, dt):
    self.perceive_fit()                      # beliefs from the real seat

    # a persistent fit gap erodes trust: the cabin ignores his body
    gap = self.belief["fit_gap"]
    gb = (gap - 0.3) * 2.4 if gap > 0.3 else 0.0
    if gb > 0:
        hands = 1.6 if self.belief["user_hands"] else 1.0
        self.mood["suspicion"] = min(1.0, self.mood["suspicion"] + dt * 0.006 * gb * hands)

    best, best_v = None, 0.0
    for goal in GOAL_CD:                     # settle · attend · calibrate
        if self.t - self.bdi["last"].get(goal, -99.0) < GOAL_CD[goal]:
            continue                          # cooldown
        if not self._pre(goal):
            continue                          # precondition
        v = self._desire(goal)
        if v > 0 and v > best_v:
            best, best_v = goal, v            # argmax wins the intention

    self.bdi["intention"] = best
    if best: self.bdi["last"][best] = self.t

    if best == "settle":                      # act on the seat (whitelisted)
        ...
    elif best == "attend":                    # recall a trace, maybe say it
        self.maybe_speak(self.think())
    elif best == "calibrate":                 # review trust, by live value
        ...
LLM mode (--reasoning llm / auto): Python still computes which goals are legal (cooldowns + preconditions above), then one model call picks the intention and words the thought together — {"intention": "…", "thought": "…"}. The answer is re-checked against the legal set (anything else keeps the argmax), throttled to ≥12 sim-seconds between calls, retried once on rate limits, and falls back to rules on any failure. Mood relax, memory decay, seat clamps and cooldowns never come from the model.
Why intention is sometimes null: that is faithful behaviour, not a bug. If every goal is inside its cooldown or fails its precondition for this tick, the agent idles with intention = null — exactly the JS bdiReason semantics. With tick_dt = 2 you see it clearly: attend (cd 3.2 s) fires every other step.

Three goals

GoalPreconditionDesirecd
settlefit_gap ≥ 0.22 and not user_hands min(2, ph·gap·(0.15 if hands else 1)), 0 below gap 0.18 — ph 1.3 setup / 0.9 ride9 s
attendalways 0.3 + 0.7·act (0.15 if memory empty) + 0.4 if suspicion > 0.63.2 s
calibratephase == "ride" 0.35 + min(0.6, (t−120)/480)·k, k ∈ {0.85, 0.5}10 s

settle actuates through the same whitelist a human input uses (actions.apply(cabin, "seat_up"/"rotate_ccw"…)) — the mind gets no privileged path past the clamps. When it can't move (bounds, hands on the controls) it thinks settleLow instead: "Lower again. Maybe I came back wrong."

Human override: any POST /api/seat stamps mind._last_user_input = mind.t; for the next 3 seconds belief.user_hands suppresses settle and multiplies its desire by 0.15 — the machine waits while you drag the dial.
04Memory System

Associative traces with exponential decay (ACT*-flavoured, exactly as the JS had it). Ride events, the experimenter's questions and chat lines all enter through the same door:

class Memory:
    def remember(self, trace_id, label, salience, important, t):
        act = min(1.0, salience + (0.1 if important else 0.0))
        self.traces.append({... "act": act, "born": t, "rehearsed": 0})
        if len(self.traces) > self.cap:          # cap 8 — FIFO evict
            del self.traces[: len(self.traces) - self.cap]

    def decay(self, dt, t):
        for tr in self.traces:
            tr["act"] *= math.exp(-self.lam * dt)        # λ = 0.004 /s
            if tr["act"] < self.floor:                   # floor 0.09
                dead.append(tr)                          # → forgot ring (6)

    def pick(self):                            # retrieval = highest activation
        return max(self.traces, key=lambda tr: tr["act"])

    def rehearse(self, tr):                    # recalling strengthens
        tr["act"] = min(1.0, tr["act"] + 0.22)

Worked example

remember("bump", salience 0.795) → act = 0.795 after 480 s: act = 0.795 · e^(−0.004·480) = 0.1166 still remembered (> 0.09) after 960 s: act = 0.1166 · e^(−1.92) = 0.0171 < 0.09 → forgotten forgot ring: [{label, age}], count++
  • Encoding: salience = max(0.35, 0.42 + impact·0.5) where impact = max(g, jolt); important kinds (bump · arrive · workzone) get +0.1.
  • Retrieval: pick() returns the strongest trace; think() then quotes THOUGHTS[trace.id] and rehearses it (+0.22).
  • Capacity: 8 traces, oldest evicted silently (FIFO); traces that decay past the floor are remembered as forgotten in the ring of 6 + a counter — the HUD shows both.
  • Chat is encoded too: POST /api/chat stores "Experimenter: …" as a trace (salience 0.5, important), so a later recall can resurface what was asked.
At λ = 0.004/s a mid-salience trace stays quotable for roughly 6–10 minutes of ride — long enough that attend keeps re-reading the pothole at 258 s while we're still motorway-bound, and short enough that the summary screen shows real forgetting by 600 s.
05Trust & Mood Dynamics

Seat fit (canonical units)

rot = seat.rotation_deg mod 360 hgt = seat.height_mm / 10 (mm → cm) dr = min(1, |rot − target_rot| / 180) dh = min(1, |hgt − target_hgt| / 8) fit = { rot: 1−dr, hgt: 1−dh, overall: 1 − (dr+dh)/2 } fitGap = 1 − overall Phill starts as-found (90° / 38 cm) → gap 0.625

Comfort — attractor blend

comfortTarget = clamp01( 0.35·rate(ROT, rot) + 0.35·rate(HGT, hgt) + 0.30·fit.overall ) comfort += (comfortTarget − comfort) · min(1, dt·0.06)

With the seat settled forward at 44 cm: 0.35·1.0 + 0.35·0.0455 + 0.30·1.0 = 0.6659 — the live snapshot converges to exactly that. The rate tables (ROT, HGT) are the thesis reference data, unchanged.

Live trust

trust.live = clamp01( 0.34·comfort + 0.40·(1 − suspicion) + 0.16·ev + 0.10·(1 − fitGap) ) where ev = clamp01(1 − jolt/0.6) worked example: comfort 0.5, susp 0.3, jolt 0.3, fitGap 0.2 = 0.34·0.5 + 0.40·0.7 + 0.16·0.5 + 0.10·0.8 = 0.61

Suspicion — set-point, not a ratchet

  • Base set-point 0.5 (persona mood.suspicion); drifts back at −0.004/s above it, +0.003/s below.
  • Priors re-baseline it for the next ride: base = clamp01(0.5 + (0.5 − prior_trust)·0.35) — a wary last ride starts this one slightly more suspicious (persisted as aggregate JSON, no personal data).
  • Event impulses: jolt > 0.3 → +0.20 susp & comfort −jolt·0.12; brake +0.07; overtake +0.05; rain +0.04.
  • Fit-gap erosion: above a 0.30 gap, +dt·0.006·(gap−0.3)·2.4, ×1.6 while hands are on the controls — the cabin ignoring his body is itself suspicious.

Routing inside Mind._chat_reply — never a fixed script:

  • seat words (seat · height · lower · raise · rotate · adjust · settle) → answers from his body's current fit, and if fitGap ≥ 0.22 it clears the settle cooldown so the BDI acts on your request immediately;
  • trust words → answered from trust_value(): ≥ 0.6 → trustOk, ≤ 0.38 → trustLow, otherwise trustMid;
  • wellbeing words → answered from the ambient mood (idleS / idleC / idleN);
  • anything else → a dry idleN line. Every inbound line is also encoded into memory.
LLM voice: with reasoning enabled the routing above becomes the fallback. The model receives the same STATE line plus the last four chat turns and writes Phill's answer (JSON-only prompt, validated, ≤240 chars). The seat-question side effect — clearing the settle cooldown so the BDI can act on the request — still runs in every mode: behaviour is Python's, wording is the model's.
