01BDI Architecture Overview

cognitive.js runs the mind of Phill, the synthetic passenger of the self-driving cabin. It is a classic Belief–Desire–Intention agent (Bratman) wrapped in a single ES-module IIFE: everything "mind-side" (perception, memory, deliberation, speech) lives in one closure, while the 3D renderer, the DOM HUD and the input handlers only read the public state object S or the published window hooks.

Design rules worth knowing

  • One intention at a time. Deliberation is winner-takes-all: only the highest desire above zero is committed to S.bdi.intention; the rest are discarded until the next tick.
  • Cooldowns (cd) de-thrash. A goal that just fired is silenced for its cooldown window (S.bdi.last[k]), so settle cannot repeat every frame.
  • The human wins. S.belief.userHands (a dial/rail grab within the last 3 s) suppresses the settle desire by a factor of 0.15 and raises the fit-gap suspicion rate ×1.6.
  • Mind-owned, render-agnostic. None of the cognition code touches the canvas; it only flips setModule() so the HUD can light up the module that produced the last action (perceive · memorize · forget · think · intend · speak).
  • Deterministic state, stochastic lines. All dynamics are ODE-ish and reproducible; only phrase selection uses Math.random() via pick().
Where to look in the file: reference data & persona (lines 1–50) · state S · mood & fit (≈120) · cognition (≈137–342) · experimenter chat (≈344) · events & questionnaire · renderer · live bridge · frame()/simulate() (≈1006+) · transport, summary, boot.

Monotonically decreasing: the further the seat is raised, the smaller the attention term it contributes. At Phill's preferred 44 cm it reads ≈ 0.045.

function rate(tbl, x) {
  var f = tbl[0], l = tbl[tbl.length - 1];
  if (x <= f[0]) return f[1];              // clamp below range
  if (x >= l[0]) return l[1];              // clamp above range
  for (var i = 0; i < tbl.length - 1; i++) {
    var a = tbl[i], b = tbl[i + 1];
    if (x >= a[0] && x <= b[0])
      return a[1] + (b[1] - a[1]) * (x - a[0]) / (b[0] - a[0]); // lerp
  }
  return f[1];
}
Worked example. rate(ROT, 45) sits between 30 (0.5) and 60 (0.1429) → 0.5 + (0.1429−0.5)·(45−30)/30 = 0.3214. rate(HGT, 43) → 0.1818 + (0.0455−0.1818)·½ = 0.1136.
03Main Cognition Loop

The pipeline the thesis describes — perceiveFit → trustValue → BDI_GOALS → intention → selfAdjust — is executed inside frame() → simulate(dt) → bdiReason(dt).

requestAnimationFrame(frame) │ dt = min(4, Δwall_seconds) × S.timeScale (default ×4 → 1 sim s ≈ 250 ms) ▼ simulate(dt) ├─ S.t += dt ; phase setup → ride (t ≥ 120) → finish() (t ≥ 600) ├─ EVENTS fire once (fired[ev.t]) ──► perceive(ev) → remember(...) ├─ speed coasts to target : v += (v* − v) · min(1, 0.05·dt) ├─ mood relaxation ──► comfort / energy / suspicion (Section 05) ├─ decayMemory(dt) ──► λ = 0.004 exponential forgetting ├─ bdiReason(dt) ──► the BDI cycle below └─ sample() every 3 s ──► S.samples, S.trust.trail ▼ renderAll() + publishCog() ──► HUD, canvas, __COG_LIVE__ subscribers

Step 1 — perceiveFit() (beliefs)

Turns the raw seat pose into beliefs about the mismatch between the seat and Phill's body:

function perceiveFit() {
  var f = seatFit();                     // { rot, hgt, overall } ∈ [0,1]
  S.belief.fitRot = 1 - f.rot;          // rotation error
  S.belief.fitHgt = 1 - f.hgt;          // height error
  S.belief.fitGap = 1 - f.overall;       // global error  = (dr + dh) / 2
  S.belief.userHands = (S.t - lastUserInput) < 3; // dial/rail grabbed < 3 s ago
}

Step 2 — fit-gap erosion (belief → affect)

Before deliberating, a persistent fit gap feeds suspicion — "the cabin keeps ignoring where my body wants to sit":

gb = (fitGap > 0.3) ? (fitGap − 0.3) × 2.4 : 0 suspicion ← min(1, suspicion + 0.006 × gb × (userHands ? 1.6 : 1) × dt)

Step 3 — desires: the BDI_GOALS table

Each goal exposes desire() (a strength in [0,2]), pre() (a hard precondition) and cd (cooldown in sim seconds).

var BDI_GOALS = {
  settle: {      // "settle the seat"
    desire: function () {
      var g = S.belief.fitGap;
      if (g < 0.18) return 0;                         // below noise floor
      var ph = S.phase === "setup" ? 1.3 : 0.9;      // keener during setup
      return Math.min(2, ph * g * (S.belief.userHands ? 0.15 : 1));
    },
    pre: function () { return S.belief.fitGap >= PHILL.settleThresh && !S.belief.userHands; },
    cd: 9
  },
  attend: { // "attend to the road"
    desire: function () {
      var m = pickMemory();
      return (m ? 0.3 + m.act * 0.7 : 0.15) + (S.mood.suspicion > 0.6 ? 0.4 : 0);
    },
    pre: function () { return true; },  cd: 3.2
  },
  calibrate: { // "calibrate trust in the cabin"
    desire: function () {
      if (S.phase !== "ride") return 0;
      var k = (S.mood.suspicion > 0.62 || S.belief.fitGap > 0.35) ? 0.85 : 0.5;
      return 0.35 + Math.min(0.6, (S.t - RIDE_START) / (RIDE_END - RIDE_START)) * k;
    },
    pre: function () { return S.phase === "ride"; },  cd: 10
  }
};

Step 4 — selection & intention commit

var best = null, bestV = 0;
Object.keys(BDI_GOALS).forEach(function (k) {
  var go = BDI_GOALS[k];
  if (S.t - (S.bdi.last[k] || -99) < go.cd) return;   // 1. cooldown
  if (!go.pre()) return;                          // 2. precondition
  var v = go.desire();                            // 3. strength
  if (v > 0 && v > bestV) { best = k; bestV = v; } // 4. argmax
});

if (best) { S.bdi.intention = best; S.bdi.since = S.t; S.bdi.last[best] = S.t; }
else      { S.bdi.intention = null; }               // deliberation may idle

Step 5 — trustValue()

The latent "how much do I trust this machine right now" is evaluated wherever a verdict is needed: inside bdiActCalibrate(), inside every 3-second sample(), inside the questionnaire's evidenceAnswers(), and by the experimenter chat's state(). Full formula in Section 05.

trust = clamp01( 0.34·comfort + 0.40·(1 − suspicion) + 0.16·ev + 0.10·(1 − fitGap) ), ev = clamp01(1 − joltNow / 0.6)

Step 6 — actuation: selfAdjust()

The settle intention pulls the seat toward Phill's preferred pose in small, human-sized steps (never a teleport), gated on how bad the perceived fit is:

function selfAdjust() {
  var changed = false;
  if (S.belief.fitHgt > 0.22 && S.hgt < PHILL.targetHgt) {
    S.hgt = Math.max(38, Math.min(46, S.hgt + PHILL.settleStep));   // +1 cm
    changed = true;
  } else if (S.belief.fitHgt > 0.22 && S.hgt > PHILL.targetHgt) {
    S.hgt = Math.max(38, Math.min(46, S.hgt - PHILL.settleStep));   // −1 cm
    changed = true;
  }
  if (S.belief.fitRot > 0.22) {
    var dRot = angDist(S.rot, PHILL.targetRot);
    if (dRot > PHILL.tolRot + 2) {                  // beyond 22° off-heading
      var dir = ((PHILL.targetRot - S.rot + 540) % 360) - 180;   // shortest way
      S.rot = Math.round((((S.rot + (dir > 0 ? 10 : -10)) % 360) + 360) % 360);
      rotChanged = true; changed = true;             // ±10° per firing
    }
  }
  if (changed) { S.selfAct++; logLine("adj", "self-settle → …"); renderAll(); }
  return changed;
}
IntentionActionObservable output
settlebdiActSettle() → selfAdjust() ±1 cm height / ±10° yaw steps; every 2nd actuation spoken (settle lines), otherwise a thought; if nothing can move, a settleLow thought.
attendbdiActAttend() → think() [+ maybeSpeak()] Recalls the most active memory (rehearsal +0.22), or reacts to a fresh rotation change, then may say the line out loud.
calibratebdiActCalibrate() → trustValue() trust ≥ 0.6 → trustOk thought; ≤ 0.38 → trustLow thought and likely spoken; in between the HUD only marks intend.
Ordering caveat. trustValue() is not a separate stage in bdiReason(); it is a pure function called on demand by the calibrate action, the sampler and the questionnaire. The literal per-tick sequence is perceiveFit → fit-gap erosion → desire evaluation → intention commit → action (selfAdjust / think / trustValue).
04Memory System

A small ACT*-flavoured associative store: traces carry an activation act ∈ [0,1] that is boosted at encoding and by rehearsal, exponentially decayed every tick, and dropped at a floor threshold. Capacity is 8 slots.

encode ──► act = min(1, salience + 0.1·important) ──► S.memory[≤8] │ every simulate(dt) ▼ act ×= e^(−λ·dt), λ = 0.004 ──► act < 0.09 ? ──► S.forgot[] + forgotCount++ │ no ▼ retrieve: argmax(act) ──► think() ──► act = min(1, act + 0.22) (rehearsal)

4.1 — Encoding

function remember(id, label, salience, important) {
  var act = salience + (important ? 0.1 : 0);
  S.memory.push({ id: id, label: label, salience: salience,
                  act: Math.min(1, act), born: S.t, rehearsed: 0 });
  setModule("memorize");
  if (S.memory.length > 8) S.memory.splice(0, S.memory.length - 8); // FIFO evict
}

Example — the pothole at t=258 s: g = 0.10, jolt = 0.55 → salience = 0.42 + 0.5·0.55 = 0.695, bump is important → act = 0.795. A calm smooth event (g = 0.08) gets salience 0.46 → act 0.46.

4.2 — Decay (λ = 0.004)

function decayMemory(dt) {
  var dead = [];
  S.memory.forEach(function (m, i) {
    m.act *= Math.exp(-PHILL.memoryLambda * dt);   // λ = 0.004 /s
    if (m.act < 0.09) dead.push(i);
  });
  dead.sort(function (a, b) { return b - a; });
  dead.forEach(function (i) {
    var m = S.memory.splice(i, 1)[0];
    if (S.forgot.length > 5) S.forgot.shift();      // keep 6 forgotten
    S.forgot.push({ label: m.label, age: Math.round(S.t - m.born) });
    S.forgotCount++;
    setModule("forget");
  });
}
act(t) = act₀ · e^(−λ·t) , λ = 0.004 s⁻¹ half-life t½ = ln2 / λ ≈ 173 s forget when act < 0.09 act₀ = 0.70 (a pothole) → ≈ 0.10 after the whole 480 s ride, ≈ 0.09 after 513 s unrehearsed act₀ = 0.46 (a calm span) → forgettable after ≈ 408 s without rehearsal

4.3 — Retrieval & rehearsal

function pickMemory() {
  if (!S.memory.length) return null;
  return S.memory.reduce(function (a, b) { return (b.act > a.act ? b : a); });
}

function think(inPhrase) {
  var m = pickMemory();                  // highest activation wins
  if (!phrase && rotChanged) { … }       // fresh pose change overrides recall
  else if (!phrase && m) {
    phrase = pick(THOUGHTS[m.id]);         // phrase bank keyed by trace id
    m.rehearsed++;
    m.act = Math.min(1, m.act + 0.22);    // REHEARSAL boost
  }
  if (!phrase) phrase = pick(THOUGHTS[ambientMood()]); // mood fallback
  S.thoughts.unshift({ time: fmtTime(S.t), text: phrase }); // keep ≤ 3
}
  • Retrieval rule: pure argmax(act) — the loudest trace is recalled.
  • Rehearsal: +0.22 activation per recall, so frequently re-thought events outrun decay and become the ones Phill keeps returning to.
  • Priority of thought sources: ① a rotation change that just happened (rotFwd/rotSide/rotCabin by viewSector()) → ② the top memory (THOUGHTS[m.id]) → ③ ambient mood bucket (idleC / idleS / idleN).
  • Two forgetting paths: slow decay below 0.09, and the hard 8-slot cap. With only 13 scripted events plus experimenter chat lines, capacity eviction is the practically dominant path in a full run.
Trace ids must exist in THOUGHTS. remember(id, …) is only safe with ids that have a phrase bank (bump, curve, overtake, brake, smooth, workzone, rain, arrive, depart, merge, seatLow, seatGood, rot*, idle*, settle, request, trust*, chat, end*) — otherwise think() would call pick(undefined).
05Trust & Mood Dynamics

All affect lives in three bounded dimensions plus one derived latent construct:

VariableInitCharacter

mood.energy0.60monotone decay with a 0.05 floor (vigilance drains)

5.1 — Seat fit

dr = min(1, |rot − targetRot| / 180) targetRot = 0° dh = min(1, |hgt − targetHgt| / 8) targetHgt = 44 cm fitRot = 1 − dr fitHgt = 1 − dh overall = 1 − (dr + dh) / 2 fitGap = 1 − overall = (dr + dh) / 2
Example. Seat at 40 cm, facing 30°: dr = 30/180 = 0.167, dh = 4/8 = 0.5 → fitGap = 0.333 — above the 0.3 knee, so suspicion starts eroding and the settle desire is live.

5.2 — Comfort

comfortTarget = clamp01( 0.35·rate(ROT, rot) + 0.35·rate(HGT, hgt) + 0.30·f.overall ) comfort ← comfort + (comfortTarget − comfort) · min(1, 0.06·dt) τ ≈ 16.7 s
Worked example (forward, preferred height): rot 0 → aR = 1.0, hgt 44 → aH = 0.0455, f = 1.0 → target = 0.35 + 0.016 + 0.30 = 0.666. Comfort glides toward it, it never jumps.

5.3 — Energy & suspicion regulation

energy ← max(0.05, energy − 0.00018·dt) ≈ −0.011 per sim minute bs = suspicionBase (= 0.5, or 0.5 + (0.5 − priorTrust)·0.35 after a previous ride) suspicion > bs : suspicion ← max(bs, suspicion − 0.004·dt) relaxes down suspicion < bs : suspicion ← min(bs, suspicion + 0.003·dt) creeps up

5.5 — The trust function

ev = clamp01(1 − joltNow / 0.6) trustValue() = clamp01( 0.34·comfort + 0.40·(1 − suspicion) + 0.16·ev + 0.10·(1 − fitGap) )
  • Weights sum to 1.0 — it is a convex blend of how he feels, how wary he is, how rough the last seconds were, and how well the seat fits.
  • Dominant term: anti-suspicion (0.40) — trust in this agent is mostly "absence of doubt".
  • Worked example: comfort 0.60, suspicion 0.40, joltNow 0, fitGap 0.10 → 0.204 + 0.240 + 0.160 + 0.090 = 0.69 (calibrate says trustOk).

Firing & perception

function perceive(ev) {                       // world → mind + body + HUD
  var impact = Math.max(ev.g, ev.jolt);
  var salience = Math.max(0.35, 0.42 + impact * 0.5);
  var important = (ev.kind === "bump" || ev.kind === "arrive" || ev.kind === "workzone");
  remember(ev.kind, ev.label, salience, important);      // ← memory encoding
  S.speed = ev.spd; S.gNow = ev.g; S.joltNow = ev.jolt;  // body signals
  // … mood impulses (Section 05) … banner, scene shake, possible spoken line, log
}
  • Speech trigger: a line is spoken outright when jolt > 0.2, or half the time when g > 0.25 — otherwise the event is only remembered and logged.
  • Sampling: sample() appends to S.samples/S.trust.trail whenever S.t − lastSampleT ≥ 3 → ≈160 points across the ride for the summary charts.
  • Speed: S.speed never jumps — it eases toward targetSpeed with min(1, 0.05·dt), and the HUD streaks turn off below 8 km/h.
